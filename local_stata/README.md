# 实证学徒 Windows 本机 Stata 助手（试验版）

1. 安装有效授权的 Stata 18、Python 3.11 或以上；在 Trae / VS Code 启动 DeepEcon Stata MCP 扩展。
2. MCP 保持 `localhost:4000`，不要开放公网端口。
3. PowerShell 在本目录运行 `./start.ps1`，访问 `http://127.0.0.1:8767/`。
4. 本机页面填写实证学徒 HTTPS 根地址，生成五分钟配对码。在网站当前练习的“本机 Stata MCP”中输入。
5. 在本机页面填写 CSV/TSV 路径。仅字段名、行数、缺失摘要和文件哈希发送给网站。
6. 网页核对方案并提交；本机助手显示完整最终代码、输入路径和工作目录。点击批准后才调用 MCP。
7. 结果先保存本机；检查拟上传 JSON，再点“确认上传以上结果摘要”。完整输入、日志、输出和 ZIP 默认保存在 `%LOCALAPPDATA%/EmpiricalApprentice/tasks`。

其他代码为试验功能，不自动拥有方法教学、统计量提取或因果核验能力。代码以本机账号权限执行；工作目录不是权限沙箱。仅批准自己理解的代码。连接凭据保存在本机 connection.json，勿分享该文件。

每个任务独立会话，120秒后请求停止并销毁该会话。断网不等于计算中断。助手重启不自动重跑，运行任务恢复时标记为中断。三方法真实执行、取消与两浏览器归属的验收结果见项目验收台账。
