- 统一颜色、字体、间距、圆角、边框、阴影与焦点规范；局部编译 Bootstrap 5.3.8 的按钮、表单、卡片、提示样式，依赖版本锁定，MIT许可随包保留。沿用静态页面和原有控制器，不迁移业务到React。
