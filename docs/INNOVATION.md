# 实证学徒：一页可核验的创新说明

面向不知道如何开始实证研究的学生，把“形成问题—准备资料—理解方法—确认方案—真实计算—解释修订—独立核验”接成学习过程。

|主张|产品中的操作|评委可检查的证据|当前限制|
|---|---|---|---|
|研究准备与计算衔接|无数据先补问题与资料；已有数据核对字典、适用性与方案，确认后执行|准备卡状态、research_revision、确认哈希、执行快照与任务日志|来源真实性仍需学生／队友核对|
|展示学习过程|保存首次解释、具体反馈和多次修订，短课完成与跳过分开记录|学习历史、报告、模型交互 ID、提示词版本与实际输出|自由文本反馈不认证独立掌握；教学效果待新手试用|
|可追溯且可复算|保留输入、单位、脚本、软件版本与数值核对结果|ZIP、分析报告、独立重跑差异表、来源状态|浏览器复算不是服务器认证；云端软件须另行验收|

模型承担补问、受约束候选方案和解释建议；计算软件产生数值，学生负责核对与修订。模型不接收逐行数据、不执行 R、不追求显著性，不将建议当作已核实来源。

演示用 [五条任务](DEMO_TASKS.md)，教育价值用 [新手试用记录](NOVICE_PILOT.md) 支持。软件数量、页面和动画服务于学习路径；尚未完成的来源、设备和部署验收如实列于 [台账](COMPETITION_EVIDENCE.md)。
