# 新手探索性试用记录模板

由队友邀请 2–3 名无实证经验学生，自愿参加，使用 P01／P02／P03 匿名编号。不记录账号密码或不必要个人信息。小规模观察不能宣称普遍教学效果；目前没有已完成参与者或得分。

## 统一任务

从无数据准备入口形成问题；再使用现有 OLS 模拟数据核对单位和方案，真实执行，解释系数与局限，查看反馈并修订，下载报告。最后识别分批或未知政策不能直接同批 DID。帮助、提示和参考答案查看均记录。

|记录项|首次操作／回答|获得的提示或帮助|修订／完成情况|
|---|---|---|---|
|是否知道下一步|待填写|待填写|待填写|
|第一次卡点与时间|待填写|待填写|待填写|
|系数及单位解释|待填写|待填写|待填写|
|关联与因果区别|待填写|待填写|待填写|
|资料缺失／方法不适用|待填写|待填写|待填写|
|报告下载与核对|待填写|待填写|待填写|

每次试用追加：匿名编号、设备与浏览器、日期、会话／任务／交互 ID、卡点所在按钮或步骤、原话、首次回答和修订。区分独立完成、得到提示、查看参考答案。
