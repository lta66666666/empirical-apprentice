## 本轮改动

| 问题 | 原因与改动 | 使用效果 |
|---|---|---|
| 陈述资料后提问，资料可能漏存 | 按陈述片段提取并保留原文出处，咨询与更正分别处理；拒绝模型从疑问句引用事实 | “医院、年度平均住院费用、2018–2022年＋费用咨询”同时保存资料并回答问题 |
| 不知道单位后反复追问 | 明确保留“待数据说明确认”；不抹去已知指标 | 有效普通回归可继续，解释不能擅自换算为元、吨等 |
| 换题残留旧研究上下文 | 保存持久换题建议，用户确认后条件创建新练习；请求编号幂等 | 原练习保留，新练习不继承数据、配对、确认或结果 |
| 本机资料建议无法应用 | 对话与行动接口共用当前输入身份，按所选引擎读取材料或配对输入 | 不再只比较浏览器输入哈希 |
| 上传后缺少下一步入口 | 材料成功后关闭材料窗，右侧提供“核对数据与方案” | 不要求先让模型重复追问或找隐藏工作台 |
| 无 DTA 输入 | 新增账号/练习归属的不可变材料与受限解析进程 | CSV、TSV、DTA统一进入资料、方案和任务 |
| DTA 标签、缺失和日期可能误用 | 数值码不转换成标签；标签与扩展缺失分类留侧车；日期格式分别识别 | `.a–.z`是缺失，`-99`不自动变缺失；非年度日期必须先预览转换 |
| 全缺失观测可能被跳过 | CSV检查只跳过真正空白物理行，保留明确空字段观测；DTA校验导入前后行数 | 缺失记录和原行号可追溯 |
| 代码只能计算后看 | 同一模板在方案核对时生成版本化只读产物，完成后逐字核验 | 可点命令、变量顺序、逗号、年份项、`fe`、`vce()`和结果统计量 |
| 教学容易串任务 | 讲解接口读取持久方案/任务；验证账号、练习、代码哈希与当前方案版本 | 迟到讲解不覆盖新的输入上下文；阅读不执行、不记成果 |
| 对应脚本不完整 | 加入类型转换、缺失规则、最小样本、面板键、同批条件、字符串编号与估计样本导出 | 三份原样脚本已在独立Stata18会话运行；不伪造云端Stata日志 |
| 统计与导出证据不足 | 统一最小样本及面板/聚类限制；保存完整协方差和维度，增加p值比较 | 未记录的省略原因保留“未记录”；不推断全部由共线或缺失造成 |
| 软件/版本标识不一致 | PDF修正Python标识；导出增加原文件、规范化、方案及代码哈希；保存三次解释版本 | 页面和导出读取同一任务记录；导出期间版本变化拒绝混合生成 |

## 数据与接口

- `POST /api/sessions/:id/research/data`：文件、可选JSON字典、版本、幂等编号。原文件与规范化文本各不超过2MB，20,000行、60列；不截断。
- `GET /api/sessions/:id/research/data/:dataId`：同账号同练习恢复材料。原文件、规范化CSV和元数据分别保存哈希。
- `POST .../data/:dataId`：`preview_year`只预览；`year`经确认新增年度列，保留原列与原文件，不自动合并观测。
- 方案/任务接受`data_id`，继续兼容既有文本输入；浏览器R读取同一规范化文本。
- `GET .../research/teaching`：持久方案或任务、命令、语法与统计量的固定讲解。
- 对话`stata_corresponding`分支：明确提问时才调用模型；只解释已保存产物，不接收客户端任意代码。
- `research_data`增量迁移；归属删除和七天清理包含未创建任务的材料。

## 简短体验路径

1. 独立候选注册→边分析边学→一键体验同批DID。
2. 核对方案→点击对应命令/语法→勾选确认→运行→结果→解释→报告。
3. 自有材料：提交材料→数据→可先选随附JSON字典→选CSV/TSV/DTA→核对数据与方案。
4. 日期为月、季、日时，在文件标签详情中预览提取年度；确认后重新核对方案。同一个体同年多行仍会被面板检查拒绝。
