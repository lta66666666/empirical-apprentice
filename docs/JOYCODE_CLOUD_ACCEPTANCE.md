## 改动说明

- 分离旧Sites与JoyCode源码，移除新目录的旧项目标识；不复制旧数据库、账号、密钥或浏览器草稿。
- 云端新增`statspai_cloud / software=python`；默认云端，无静默回退。
- 同容器只允许精确的127.0.0.1:8000内部通道，签名及归属继续校验；Python估计子进程不继承模型密钥。
- 根Dockerfile按允许清单复制构建来源，补齐原构建漏掉的生成脚本；非root运行，8080入口，监督两个服务。
- 页面主标题“分析结果”，技术详情收起；对应.do明确未执行，哈希绑定任务与方案。复现包使用Python脚本，保留实际软件与推断。
- 数据上传前提示服务器处理和七天到期，原始观测不发模型。
- 修复云端执行方式被草稿白名单拒绝的问题；前端不再将所有非浏览器引擎误判成本机助手。
