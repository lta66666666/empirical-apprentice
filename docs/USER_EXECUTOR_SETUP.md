# 云端计算接入：用户准备与技术实施

更新：2026-10-08。先完成云端 R，再办理 Stata；EViews 等待厂商提供适用的网站方案。本文件是准备清单，不是部署成功证据。

## 1. 用户先准备云端 R 资源

- 学校提供或自行取得的一台 Linux 服务器：至少 2 vCPU、4 GB 内存、20 GB 可用磁盘；有公网连接和持久存储，允许安装 Docker 与配置服务。
- 一个可管理 DNS 的域名或子域名，或已具备可信 HTTPS 的托管执行地址。Sites 分配的网址继续用于前端；计算节点使用独立地址。
- 服务器登录权限：SSH 密钥由用户在自己的设备配置。聊天只提供主机地址、系统版本、SSH 用户名和所用域名，不提供密码、私钥或令牌。
- 自有域名方案：DNS 指向服务器，80／443 可达，SSH 限于维护来源，应用端口 8000 保持本机绑定。

## 2. 技术实施与验收

1. 检查 executor/Dockerfile 的 R 4.6.1、fixest 0.14.2、jsonlite 2.0.0 能否实际安装；构建没有通过前不写“容器可用”。
2. 在服务器安全生成 EA_NODE_SECRET，部署 executor/compose.yaml。持久卷保存任务；仅一个应用进程和一个任务 worker。
3. 用 executor/Caddyfile 配置反向代理和可信 HTTPS。主机版 Caddy 转发到 127.0.0.1:8000；容器版代理需要另核对网络地址。
4. 在 Sites 运行时设置 EXECUTOR_URL 为 HTTPS 节点基础地址，将 EXECUTOR_SECRET 设为 secret，并与节点密钥一致。不要在线上设置 EXECUTOR_LOCAL_TEST。
5. 实测签名拒绝、归属隔离、三方法、关闭网页后恢复、取消／超时、复现包、版本和留存同步。设置两项变量不等于验收通过。

部署细节见 ../executor/README.md；现有模型密钥只用于教学模型，不是计算节点凭据。

## 3. Stata 由用户／学校确认授权

联系学校软件许可管理员，或 StataCorp 的报价／许可部门。说明：Linux 服务器安装 Stata，由公开教学网站为匿名学生或评委排队运行固定 OLS、固定效应与同批 DID，最多一个同时运行任务；说明是否收费、开放人群、预计人数与使用时间。

询问现有许可是否覆盖这种服务器计算和外部网页访客；若不覆盖，请厂商给出适用许可、Linux 安装方案和报价。普通个人安装不能证明网站用途获准。书面确认后再安装、配置并验收；不要把许可证或序列号提交聊天或仓库。

可自行发送的咨询文字：

> 我们开发一个实证教学比赛网站，拟在 Linux 服务器运行 Stata，由网页访客提交数据并确认固定模型，服务器单任务排队估计。访客包括学生、队友、教师及评委。请确认现有学校许可是否允许这种用途，特别是匿名或校外访客；如不允许，请说明适用的服务器／网站集成许可、安装方式和报价。我们不会向访客提供任意 Stata 命令执行入口。

## 4. EViews

官方 COM 文档明确限制 Web server access。先向厂商描述同样的网站用途，询问是否有可授权的集成方案及部署条件。未取得方案前继续显示未接入；R 与 Stata 节点不自动提供 EViews。

## 浏览器中断的现状

代码在页面离开时发出中断；服务端也会在运行任务超过 30 秒未续心跳时标记中断。浏览器每 10 秒尝试续心跳。用户提供的“已中断”页面不足以判断究竟是离开页面还是心跳失联。

可先独立初始化浏览器 R，看到环境就绪后再重新核对并创建任务，执行时保持页面打开。先收集是否刷新／进入后台以及初始化日志；这条路径仍需真实设备检查。云端 R 联通后可在关闭网页后继续计算。
