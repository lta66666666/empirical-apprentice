阶段 01 · 8–12 分钟

从现象到研究问题

主线：同批手算小实验

区分描述与因果，知道这门课要解决哪类问题。

成果：一张研究起点卡

**主线模拟案例：** 某节能政策 2015 年 1 月起在 A、B 两市试点，C、D 两市未试点；观察 2013–2016 年各城市年度能源使用量。全部为教学虚构。 **实证研究 = 用可观察的数据回答问题。** 「A 市用能下降了」是描述；「政策造成了下降」是因果判断，需要额外证据。 本课练第二类：如果没有政策，试点城市会怎样？这个看不见的结果叫**反事实**。

一步一步怎么做

1. 从具体困惑开始：为什么一些城市用能下降了？ 2. 明确任务：描述变化、找关联、预测，还是评估政策作用？ 3. 先写对象和结果，再考虑方法。

跟着示范理解

**补课与成绩：** 补课学生分更高，可能与家庭支持、原有成绩有关。 看到差异不足以说补课造成差异。

容易踩的坑

- 不要把所有实证问题都改写成因果问题。

练习 1

“试点城市的能源使用量下降了”和“政策造成了下降”的差别是什么？
  • A. 没有差别，先发生政策就能说明因果。
  • B. 前一句描述变化，后一句提出需要额外证据支持的因果判断。
  • C. 只有因果问题才算实证研究。
完成后再核对示范

练习 2

用历史用电量预报下月需求，主要属于哪类任务？
  • A. 预测。预测准确并不自动解释政策因果效应。
  • B. 因果。只要用了历史数据就能证明原因。
  • C. 不属于实证，因为没有政策。

阶段 03 · 15–20 分钟

定对象、变量与文献

主线：同批手算小实验

把方向变成可测量的研究问句，并知道文献帮什么。

成果：研究问题、变量与文献卡

**一个研究问题要讲清四件事：什么政策、影响谁、观察什么结果、想判断什么关系。** 结果变量要具体：能源总量还是强度？城市还是企业？单位是什么？ 文献的作用：看别人问过什么、用过什么数据、你还缺什么证据——不是照搬结论。

一步一步怎么做

1. 用政策卡确定干预与覆盖对象。 2. 写明主要结果的定义、单位、来源。 3. 写一句可回答的问题；从关键词检索最相关的 1–2 篇文献。 4. 记录文献的样本、变量、方法、局限，标注哪些可借鉴。

跟着示范理解

**从大到小：** “研究绿色发展” → “研究城市节能政策” → “节能试点是否降低城市年度能源使用量？” 能源强度 = 用能 / 产出，与总量回答不同问题，不能互换。

容易踩的坑

- 政策之后的中间变量不应未经讨论就当控制变量。

阶段 04 · 18–25 分钟

数据、清洗与变量编码

主线：同批手算小实验

读懂面板数据，掌握 treated/post/did 编码，并处理重复与缺失。

成果：数据可得性清单与清洗日志

**面板数据：同一批单位在多个时期的记录。** 每行 = 城市 × 年份。 试点统一从 2015 年 1 月开始；A、B 为试点组，C、D 为对照组，覆盖 2013–2016。 本课三个核心编码（同批二期简化版）： • **treated**：是否试点组。1 = 试点城市，0 = 非试点城市。 • **post**：是否政策后。1 = 政策实施当年及以后，0 = 之前。 • **did = treated × post**：只有「试点城市 × 政策后」的行是 1，其余都是 0。 示例：C 市是非试点，2015 年是政策后 → treated=0, post=1, did=0。

一步一步怎么做

1. 必需字段：城市、年份、结果值、treated、post。 2. 按字段找来源，先试取 2 城市 × 2 年份确认能读出数值。 3. 用“城市+年份”查唯一性；完全重复与同键不同值分开处理。 4. 查缺失原因；本例用模拟补充表恢复，真实研究须追溯可靠来源。 5. 输出清洗日志：原始 17 行 → 去重复 1 行 → 补缺失 1 格 → 保留 16 行。

跟着示范理解

A 市 2014：treated=1, post=0, did=0 A 市 2015：treated=1, post=1, did=1 C 市 2015：treated=0, post=1, did=0（日历进入政策后，但该市没接受政策）

容易踩的坑

- 只有政策前数据无法算前后变化。 - 缺失值不是零。 - 合并失败的记录不能默认成“未试点”。

阶段 05 · 18–25 分钟

看图与手算双重差分

主线：同批手算小实验

读懂组均值趋势，用两次相减算出 DID。

成果：图表观察卡与 DID 计算卡

**DID = 两次相减。** 试点组变化 − 对照组变化。 先算各自「后 − 前」，再相减。对照组帮你扣除共同变化（如经济周期、天气）。 试点组 2014→2015：101 → 81；对照组：99 → 94。

一步一步怎么做

1. 看图：政策前两组水平与斜率，政策后变化方向与幅度。 2. 算试点变化、对照变化，保留正负号与单位。 3. 相减得 DID，写一句含义。 4. 注意：试点组全部降幅不都是政策效果；图不能证明平行趋势。

跟着示范理解

试点变化 = 81 − 101 = −20 对照变化 = 94 − 99 = −5 DID = (−20) − (−5) = −15（万吨标准煤）

容易踩的坑

- 不能把试点组全部降幅都算政策效果。 - DID 符号取决于相减顺序。

一步一步怎么做

阶段 07 · 18–25 分钟

假设检查与结果解释

主线：同批手算小实验

理解平行趋势、置信区间，联合解释方向、幅度与局限。

成果：威胁清单与四句话结果解释

**平行趋势：** 没有政策时，处理组与对照组的变化应可比。这个反事实看不见。 政策前走势是诊断，不是证明。「不显著」≠ 证明无差异。 下面的事件研究图是**独立的人为示意图**，未由前面的 4 城市数据估计。 解释结果四步：观察 → 幅度 → 不确定性 → 局限。对数系数要做指数变换。

一步一步怎么做

1. 解释为什么这组对照能代表无政策时的变化。 2. 列出至少两种威胁（同期冲击、选择机制、外溢等）及所需证据。 3. 报告具体估计与区间，不只看星号。 4. 对数系数 −0.22 ≈ 100×(exp(−0.22)−1) ≈ −19.75%，含义看模型。

跟着示范理解

点估计 −2，区间 [−8, 4]：与下降、零或一定上升都相容，不能写“政策无效”。 区间只表达抽样不确定性，不消除选择偏误。

容易踩的坑

- 区间跨零不等于证明没效果。 - 事后显著不自动证明因果。

阶段 08 · 15–20 分钟

形成研究备忘录

主线：同批手算小实验

把问题、证据、分析和局限连起来，知道下一步做什么。

成果：一页研究备忘录与个人行动清单

**终点是一份可审阅的备忘录，不是“我学会了”。** 串起：问题 → 政策证据 → 文献 → 数据与清洗 → 比较设计 → 结果 → 局限与下一步。 模拟结果不是真实发现；未核实信息要分开标注。

一步一步怎么做

1. 回顾各阶段成果卡，补齐空项；不会的写成具体待办。 2. 每个数字能追溯到数据、代码或明确标注的教学示意。 3. 写清模拟 vs 真实。 4. 导出学习记录。选择真实政策或自己的想法进入研究蓝图。

跟着示范理解

**小实验备忘录摘要：** 4 个模拟城市，原始 17 行去 1 重复补 1 缺失得 16 行。 2014–2015 均值 DID = −15 万吨标准煤。人为数据，未做可靠推断，不能形成真实结论。 下一步：核实自己题目的政策时间、数据覆盖与比较对象。

容易踩的坑

- 没有数据或对照时应调整问题，不必强行套 DID。 - 零结果与不确定结论也有价值。
