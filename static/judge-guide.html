建议的 5 分钟路线

1

进入「边分析边学」，注册或登录后打开一个示范练习。入口：首页 → 边分析边学；已有账号可直接登录。

2

使用内置同批 DID 模拟数据，观察对话助手如何补问对象、变量、观察时期与来源。模拟数据会明确标注；它不是真实来源证据。

3

核对候选方案与执行环境，只有勾选确认后才提交计算。可先使用浏览器 R；真实 Stata 需本机助手与有效 Stata 18 许可，条件见本机手册。

4

在结果页查看样本量、系数、标准误和区间，提交解释与修订，再导出学习报告、分析报告与复现包。解释与计算分开记录；显著不等于因果。

5

在记录页查看 Agent 交互证据：提示词、输入摘要、输出与失败原因，按需下载 MD / JSON。真实模型调用是否发生，以记录中的实际响应为准。

现场验证真实 Stata（约 2 分钟）

  1. 现场演示使用准备好的 Windows 电脑，确认已安装并授权 Stata 18，本机助手已启动。
  2. 在网页「提交材料 → 使用本机 Stata（试验）」输入助手生成的六位配对码。
  3. 选择示范 CSV，网页核对方法、变量、面板设定与推断方式后提交。
  4. 本机助手显示完整 estimate.do，现场人员批准执行；完成后另批准上传结果摘要。
  5. 结果页应显示 Stata 18、命令、样本量与系数；复现 ZIP 内含代码与日志。
只看网页、没有本机助手或 Stata 许可时，真实 Stata 不可用。此时应演示浏览器 R 或 StatsPAI，并明确标注软件，不能把其他软件结果说成 Stata。
