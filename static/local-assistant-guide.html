本机助手安装与配对手册

这份手册只讲一件事：如何在你自己的 Windows 电脑安装本机助手，并让它与实证学徒网页配对，用你本机已授权的 Stata 执行 OLS、固定效应和同批 DID。

网页本身不能访问你电脑的 localhost；真实 Stata 必须通过本机助手执行。原始数据留在本机，网页只接收字段摘要、哈希和你单独批准上传的结果。

一、先确认你属于哪种情况

测试方式能否使用真实 Stata怎么做
在自己电脑打开网页，并安装本机助手可以按本手册安装、配对；电脑上必须有有效许可的 Stata 18
只打开网页，没有本机助手不可以只能使用浏览器 R 或云端 StatsPAI（Python）
远程访问网页，Stata 在另一台电脑不可以网页无法连接那台电脑的 localhost；请使用现场准备好的机器
如果你没有 Stata 安装和许可证，请不要下载助手后声称“能跑 Stata”。助手包不包含 Stata、许可证或 Python 运行时。

二、安装前检查

  • Windows 10 或 11，64 位。当前助手只提供 PowerShell 启动脚本，不支持 macOS / Linux。
  • Python 3.11，64 位。setup.ps1 会强制检查版本与位数；其他版本会直接拒绝。
  • Stata 18，64 位，且许可证有效。模板使用 version 18.0；Stata 17 或 Stata 19 会被拒绝。安装目录下应存在 utilities/pystata/config.py。
  • 可访问互联网。首次安装依赖和网页配对都需要网络；依赖固定在本包 requirements.lock 中。
  • 端口 4000 / 8767 保持本机使用。不要在路由器或云服务器上开放这两个端口。

三、下载与安装

1. 下载并解压

点击页面左侧或本页顶部的「下载 Windows 本机助手」，得到 local-stata-assistant.zip。解压后目录中应包含 local_stata/。

2. 安装固定依赖

在解压后的目录打开 PowerShell，执行：

cd local_stata
.\setup.ps1 -Python "C:\完整路径\python.exe"

-Python 必须指向 Python 3.11 64 位的 python.exe。安装会在本目录创建 .venv，并核对 statsPAI / stata-code 的固定版本。

3. 启动助手

.\start.ps1 -StataHome "C:\Program Files\Stata18"

看到 Local assistant: http://127.0.0.1:8767 后，用浏览器打开 http://127.0.0.1:8767/。

如果提示「此路径未找到 Stata 自带的 PyStata」，说明 -StataHome 指错了目录。请指向包含 utilities/pystata/config.py 的 Stata 安装根目录。

四、连接网页并配对

在助手填写网站地址必须是 HTTPS 站点根地址
生成六位配对码由本机助手生成
在网页输入配对码提交材料 → 使用本机 Stata
双方显示已连接再选择数据与方案
  1. 在助手页面填写网站根地址，例如 https://你的站点域名；不要带路径、查询参数或末尾多余字符。
  2. 点击生成配对码，助手会显示六位数字。
  3. 登录网页，进入当前练习：提交材料 → 使用本机 Stata（试验）。
  4. 在「连接与助手设置」中输入六位配对码，点击配对当前练习。
  5. 回到助手确认状态变为已连接；网页刷新后应能看到当前设备。
  6. 在助手选择 CSV 或 TSV，点击读取字段摘要。若使用内置示范案例，可在网页点「在助手准备模拟数据」，无需手动找文件。
配对码属于一次性连接凭据，不要截图发到公开群聊；connection.json 也不要分享。

五、执行并上传结果

  1. 在网页选择方法（OLS / 固定效应 / 同批 DID）、结果变量、解释变量、面板个体与年份等。
  2. 软件选择真实 Stata（默认），并选择桥接器（见下一节）；核对方案后提交。
  3. 助手收到冻结任务后，会显示完整 estimate.do、参数、输入哈希和工作目录。
  4. 在本机核对无误后点击批准执行。单任务最长运行 120 秒；执行期间不要重复提交。
  5. 执行完成后，本机先保存结果；网页需要你另行批准上传结果摘要后才会显示实际 Stata 结果。
  6. 结果页可查看样本量、系数、标准误和区间；复现 ZIP 内含 estimate.do、execution.log 和结果 CSV。
批准执行和批准上传是两次独立动作。只批准你理解并核对过的代码；不要批量确认陌生任务。

六、两种 Stata 桥接器

桥接器适用情况需要保持运行
现有 Stata MCP（默认） 电脑已安装 Trae / VS Code 的 Stata MCP 扩展，并已连接到本机 Stata 编辑器与扩展运行，http://127.0.0.1:4000 可访问；可在命令面板执行 Stata: Test MCP Server Connection
stata-code / PyStata（试验） 没有编辑器扩展，但 Stata 18 自带 PyStata 可用 Stata 安装目录与 STATA_HOME 正确；仍需要有效许可证

两种桥接器都只执行真实 Stata。StatsPAI 是 Python 计算，不会操控 Stata.exe，结果页会明确标注软件，不能冒充 Stata。

七、常见问题

现象处理
Requires Python 3.11 64-bit安装 Python 3.11 x64，并用 -Python 指向其完整路径；不要用 3.12/3.13 或 32 位版本。
此路径未找到 Stata 自带的 PyStata核对 -StataHome 是否指向 Stata 18 根目录，并确认 utilities/pystata/config.py 存在。
网页显示助手未连接确认 8767 页面能打开、网站地址是根地址、配对码未过期；必要时重新生成配对码后再配对。
No valid session ID provided 或 4000 不通重启编辑器 / Stata MCP 扩展，刷新客户端连接；不要重复添加同名 MCP 配置。
Stata 版本报错当前模板只接受 Stata 18；Stata 17/19 需另行适配，不能强行改版本号。
执行超时或取消后担心残留本机助手会按任务取消并尝试停止进程；MCP 路径的强制终止能力有限，超时后请检查 Stata 进程并在助手刷新状态。
网页刷新后看不到结果结果可能仍在本地「待同步」；恢复网络后刷新，不要自动重跑；上传仍需单独批准。

八、安全边界

  • 助手以你的 Windows 账号权限执行代码，工作目录不是权限沙箱；只批准你理解的内容。
  • 原始数据、日志、原生结果和复现包保存在本机 %LOCALAPPDATA%\EmpiricalApprentice\tasks；网站下载不包含原始数据。
  • 4000 与 8767 只监听回环地址，不要端口转发到公网。
  • Stata 许可证必须由使用者本人合法持有；本助手包不分发 Stata、许可证或序列号。
  • AI 生成的代码只是待批准草稿，不构成执行授权；数值显著也不自动证明因果。

现场演示建议

最稳妥的方式是准备一台已经安装 Stata 18、Python 3.11 和本机助手的 Windows 机器，现场人员只在这台机器上完成配对与批准；自己的电脑仅用于打开网页。这样既避免现场安装失败，也避免跨机器使用 Stata 许可证的合规问题。

若只能远程访问网页，请明确说明真实 Stata 不可用，演示浏览器 R 或云端 StatsPAI，不要用其他软件结果冒充 Stata。
